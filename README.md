# Layangan — Majalengka Game

Terbangkan layangan Sunda di atas sawah terasering Argapura, Majalengka.
Kumpulkan padi, wajit, dan angklung, hindari layangan lawan, dan capai
Talaga Remis.

## Cara main

Buka `index.html` di browser (atau sajikan folder ini lewat server statis
apa pun). Tekan **Space** untuk mulai.

## Kustomisasi

Semua parameter gameplay (kecepatan angin, jarak finish, kepekaan kemudi,
skor pickup, volume) bisa diubah di `tune.json` tanpa menyentuh kode.

## Teknologi

HTML5 + JavaScript murni, tanpa build step. Aset gambar WebP, audio MP3,
font WOFF2 — semuanya lokal di repo ini.
